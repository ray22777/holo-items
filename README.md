# Holo Items
A **client-sided** mod that displays item names above item entities, like name tags. This makes it easier to identify items, especially in modpacks with a large variety of different items.

To open config for the mod, use the command `/holoitems` or by using Mod Menu for Fabric or the built in (neo)Forge config menu.

### Features
- **Display Item tooltips**
- **Fully configurable text formatting**
- **Hover/Always on mode**
- **Configurable distance limit**
